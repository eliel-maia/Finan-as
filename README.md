# Agenda Financeira PWA

Aplicativo web progressivo (PWA) de controle financeiro pessoal baseado em grade mensal (estilo agenda), com suporte a banco de dados local (IndexedDB via Dexie.js), relatórios financeiros mensais, recorrência de contas e backup em formato JSON.

## Funcionalidades
* **Visão de Calendário Mensal:** Navegação por gestos (*swipe* lateral), botões ou seletor rápido de mês/ano.
* **Status por Cores:** Contas pagas em verde e pendentes em laranja.
* **Modo Offline & PWA:** Totalmente funcional sem internet após a instalação no celular ou computador.
* **Backup e Restauração:** Exporte e importe seus dados com facilidade.
* **Hospedagem Recomendada:** Cloudflare Pages ou GitHub Pages.
